# Markdown 示例用例

下面是一组常用 Markdown 语法示例，便于快速参考与测试。

---

## 标题
# H1
## H2
### H3

## 段落与换行
这是第一段。

这是第二段。  
（末尾两个空格表示换行）

## 强调
*斜体*，**加粗**，***加粗斜体***，~~删除线~~

## 列表
- 无序项 1
- 无序项 2
    - 嵌套项 a
    - 嵌套项 b
1. 有序项 1
2. 有序项 2
     1. 嵌套有序 a
     2. 嵌套有序 b

## 任务列表
- [x] 已完成项
- [ ] 待办项

## 链接与自动链接
这是一个内联链接：[示例站点](https://example.com "示例标题")。  
参考式链接：[百度][baidu]

[baidu]: https://www.baidu.com "百度"

自动链接：<https://example.com>，电子邮件：<you@example.com>

## 图片
内联图片：  
![示例图片](https://via.placeholder.com/150 "占位图")

## 行内代码与代码块
行内代码：`const x = 1;`

多行代码块（指定语言以启用高亮）：
```js
// JavaScript 示例
function greet(name) {
    console.log(`Hello, ${name}!`);
}
greet('World');
```

Shell 示例：
```bash
# 安装依赖
npm install
```

## 代码差异（diff）
```diff
- 旧代码行
+ 新代码行
```

## 引用
> 这是一个区块引用示例。
>> 嵌套引用

## 表格
| 名称   | 年龄 | 说明       |
|-------:|:----:|:-----------|
| Alice  |  30  | 开发人员   |
| Bob    |  25  | 设计师     |

对齐示例：
| 左对齐 | 居中 | 右对齐 |
|:-------|:----:|------:|
| a      |  b   |     c |

## 水平线
可以使用三个短横线或星号分隔：
---

## 脚注
示例脚注[^1]。

[^1]: 这是脚注内容。

## HTML（原生）
你可以在 Markdown 中直接嵌入 HTML：<kbd>Ctrl</kbd> + <kbd>C</kbd>。

## 转义字符
想显示星号：\*不是斜体\*

## Emoji（视渲染器支持）
这是一个笑脸 :smile:，以及心形 :heart:.

## 数学公式（渲染器支持）
行内公式：$E=mc^2$  
块级公式：
$$
\int_0^1 x^2 \,dx = \frac{1}{3}
$$

---

以上示例覆盖常用 Markdown 语法，复制并修改以适配你的文档需求。
